# 万象键盘 Android 兼容测试版

基于同目录下的 `WanxiangSkin`，独立维护安卓兼容配置。原 iOS 皮肤目录保持不变。布局、普通按键、字号、配色沿用原版；图标使用测试时的同名内置字形。

## 来源及发布状态

**此版本为草稿，图标素材的 Android 分发授权尚未解决，暂不接入自动发布。**

字体内的多数图形来自 Apple 系统图标，不属于仓库 MIT 许可。图标来源、适用范围及合并前待解决事项见 [fonts/NOTICE.md](fonts/NOTICE.md)。标注出处不能替代授权。该声明也适用于生成脚本产出的字体。

## 配置与兼容改动

- 默认中文 26 键，可配置 9/14/17/18/26/27 键；支持横竖屏、深浅色。
- 内置 83 种图标的 regular/medium 字形，作用范围限定于字体私用区。
- Z 下滑进入万象 `V` 计算模式并切到数字键盘，改用计算器图标；英文键盘也提供入口。14/18 键的原计算入口同步修正。
- 固定与滑动剪贴板入口均先读取当前系统剪贴板，再打开元书剪贴板面板。
- 日期快捷键由 `orc` 修正为 `orq`；动作使用 `shortcut`；默认移除 iOS App Store 搜索入口。

核心配置在 `jsonnet/Custom.libsonnet`，布局和参数说明可参考同级 `WanxiangSkin` 的源码及上级使用说明。计算器、日期、金额转换等功能需要已部署相应万象方案和 Lua 模块。

## 本地导入测试

将整个 `WanxiangSkin-Android` 文件夹压缩为 ZIP 后改为 `.cskin`，在元书皮肤页面导入，选择「万象键盘 Android」。修改配置后重新运行 `jsonnet/main.jsonnet`。

图标字体的许可限制仍适用；本段用于描述测试过程，不授予向第三方分发该字体的权利。

## 验证范围

已在 vivo X200 Ultra 上由使用者测试原测试包，反馈可用；独立目录与显示名称调整后的版本仍需安装确认。

静态检查覆盖全部六种布局，共 77 份输出和 38 组深浅色配对；核对图标范围、计算器动作、剪贴板入口一致性和日期触发词。深浅色的高度、布局、边距、字体和动作一致，仅颜色不同。检查方法见 `Python_Tools/WanxiangAndroid/README.md`。

剪贴板的持久历史由元书应用管理，本皮肤不实现历史数据库，也不能恢复未记录的内容。系统主题切换后底部出现空白时，可检查元书「键盘底部安全区域」设置。
